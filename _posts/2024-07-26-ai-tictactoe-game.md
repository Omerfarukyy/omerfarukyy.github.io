## About The Project
An intelligent Tic-Tac-Toe game developed for Harvard's **CS50AI** course. It features an automated adversary that calculates optimal moves using the adversarial **Minimax** game-tree search algorithm, making the computer opponent completely unbeatable.

### Highlights
- Full recursive depth search via **Minimax algorithm**
- Optimal decision trees accounting for adversarial human input
- Clean **Python** GUI interface and game engine architecture
