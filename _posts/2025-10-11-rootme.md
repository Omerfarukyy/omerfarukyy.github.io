```jsx
find / -user root -perm /4000 

ChatGPT:
Bu komutun amacı, sistemde root’a ait SUID bit set edilmiş dosyaları bulmaktır.

Parça parça açıklayayım:

1. find /

Root dizininden (/) itibaren tüm dosya sistemini tara.

2. -user root

Sahibi root olan dosyaları ara.

3. -perm /4000

SUID (Set User ID) biti aktif dosyaları seç.

4000 → SUID bitini ifade eder.

/ işareti → "dosyada bu izinlerden en az biri set edilmişse" anlamına gelir.

📌 SUID nedir?

Bir dosyanın SUID biti açıksa, o dosya çalıştırıldığında dosyanın sahibinin yetkileriyle çalışır.

Yani root’a ait bir SUID dosyası → normal kullanıcı çalıştırsa bile komut root yetkileriyle çalışır.

Örn: /usr/bin/passwd → şifre değiştirmek için SUID kullanır.

```
