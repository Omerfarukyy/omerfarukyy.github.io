## About The Project

This repository documents my day-by-day programming journey, practical code exercises, automation utilities, interactive games, and web applications built during the **100 Days of Code: The Complete Python Pro Bootcamp**. Below is a breakdown of the projects and concepts covered day by day, extracted directly from my repository logs and commits.

---

### Days 17–23: Object-Oriented Programming (OOP) & Graphical Games
* **Day 17:** Quiz Game Engine using Object-Oriented Programming (OOP) architectures and custom classes.
* **Day 18:** Turtle Graphics Exploration, Tuples, RGB Color Models, and a Damien Hirst Dot Painting Generator.
* **Day 19:** Event Listeners, State Management, Higher-Order Functions, and an Interactive Turtle Race game.
* **Day 20–21:** The classic **Snake Game** built from scratch utilizing inheritance, list slicing, and OOP graphics in Python.
* **Day 22:** **Pong Game** built with custom paddle physics, collision handling, and scoreboard state in Turtle GUI.
* **Day 23:** **Turtle Crossing Capstone Game** (a Frogger-style road crossing game) featuring traffic speed progression and level upgrades.

---

### Days 24–30: File System I/O, CSV Handling, Pandas & GUI Development
* **Day 24:** Working with local filesystem files and directories: Upgraded Snake Game High-Score persistence and a Mail Merge automation tool.
* **Day 25:** CSV File handling and foundational **Pandas** library exploration: Built an interactive U.S. States guessing game.
* **Day 26:** List & Dictionary Comprehensions in Python and Pandas: Built a NATO Phonetic Alphabet spelling transformation app.
* **Day 27:** Graphical User Interface (GUI) development with **Tkinter** and mastering functional parameters (`*args` and `**kwargs`): Unit converters and desktop widgets.
* **Day 28:** Desktop **Pomodoro Productivity Timer** GUI tool featuring automated work-rest cycle countdowns built with Tkinter.
* **Day 29:** **Password Manager App** featuring GUI generation, strong password randomization, and local credentials safe-keeping.
* **Day 30:** Exception Handling (`try`, `except`, `else`, `finally`) and JSON serialization: Upgraded the Password Manager with JSON indexing and enhanced error catching on the NATO spelling project.

---

### Days 31–40: Intermediate APIs, Web Endpoints & Automated Alerts
* **Day 31:** **Flash Card Capstone Project**: An interactive language translation and vocabulary memorization desktop application using Tkinter and Pandas.
* **Day 32:** Automated Birthday Wisher: Managing dates and sending scheduled automated celebratory emails using `smtplib` and `datetime`.
* **Day 33:** Application Programming Interfaces (APIs) & HTTP requests: Built a Kanye West Quotes GUI app and an **ISS (International Space Station) Overhead Tracker** that alerts via email when the ISS passes overnight above your coordinates.
* **Day 34:** **Quizzler App**: A dynamic trivia GUI app integrated with the Open Trivia DB API utilizing advanced Python type hints and boolean verification.
* **Day 35:** Rain Alert Weather SMS Notifier: Utilizing the OpenWeatherMap API, environment variables, and Twilio API to dispatch morning rain warnings via SMS.
* **Day 36:** Stock Market Trading Alert App: Tracking significant equities fluctuations and fetching latest correlated financial news articles via SMS.
* **Day 37:** Habit Tracking Application utilizing HTTP POST/PUT/DELETE requests and graphing user activities via the Pixela API.
* **Day 38:** Exercise & Workout Tracker App utilizing Google Sheets integrations, Sheety API, and NLP exercise parsing via Nutritionix API.
* **Day 39–40:** Flight Deal Finder & Flight Club: Structuring modular capstone projects to scan flight price drops and alert subscribers via SMS/email.

---

### Days 41–53: Web Scraping & Browser Automation
* **Days 41–44:** Fundamentals of modern Web Design, semantic HTML5 structures, and CSS stylesheets.
* **Day 45:** Web Scraping data ingestion and parsing HTML trees utilizing **BeautifulSoup**.
* **Day 46:** "Musical Time Machine": Scraping Billboard Top 100 historic chart data via BeautifulSoup and automatically generating curated Spotify playlists using **Spotipy**.
* **Day 47:** Automated Amazon Price Tracker: Scraping target product listing pages with headers and triggering custom price-drop notification emails.
* **Day 48:** Browser Automation with **Selenium WebDriver**: Automated elements interaction and designed an unassisted Game Playing / Cookie Clicker bot.
* **Day 49:** Automated Career Assistant: Using Selenium to automate targeted job applications on professional networks like LinkedIn and automating internet connection speed complaint alerts to Twitter/X.
* **Day 51–52:** Instagram Follower Bot: Developing an organic follower networking and engagement bot utilizing Selenium WebDriver routines.
* **Day 53:** Data Scraping Capstone Project: Combining **BeautifulSoup** parsing with **Selenium** automated data entry forms to scrape and catalog Zillow real estate listings into structured tracking sheets.

---

### Days 54–62: Full-Stack Web Development (Flask & Bootstrap)
* **Days 54–55:** Introduction to backend web development with **Flask**, URL routing, and mastering advanced Python Decorators; Built an interactive "Higher or Lower" URL guessing web game.
* **Days 56–57:** Rendering static HTML, CSS, and JS files within Flask architectures and harnessing dynamic **Jinja2** template engines to serve API-backed technical blog platforms.
* **Days 58–59:** Responsive layouts with **Bootstrap**: Refactored and upgraded the web blog interface with modern responsive UI patterns and interactive forms.
* **Day 62:** "Coffee & Wifi" Web Application: Integrating Flask, **WTForms**, custom validation routines, Bootstrap formatting, and CSV backend databases to map work-friendly cafes.

---

### Days 72–81: Data Science, Analytics & Machine Learning
* **Day 72:** Data Exploration & Analytics: Using **Pandas** and **Matplotlib** to parse historical datasets and chart longitudinal statistics regarding programming language usage and popularity.
* **Days 73–74:** Interactive Jupyter Notebooks & Dataset Visualizations: Comprehensive data science exploration analyzing structural trends, color spectra, set complexity, and theme historical trajectories across Lego manufacturing datasets.
* **Day 81:** Machine Learning & Statistical Prediction: Conducting deep multivariate data analysis utilizing **Pandas, NumPy, Seaborn, and Matplotlib**, alongside implementing **Scikit-Learn** Linear Regression modeling to evaluate predictors and estimate residential real estate valuation outcomes.
