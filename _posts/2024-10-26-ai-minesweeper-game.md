## About The Project
Developed as part of Harvard's **CS50AI** coursework, this project implements a functional classic Minesweeper puzzle accompanied by an autonomous AI solver that applies propositional logic and knowledge-based inference to deductively locate safe cells and flag potential mines.

### Highlights
- Knowledge representation with propositional logic rules
- Inference engine to derive safe moves from partial board constraints
- Written in **Python** with an intuitive graphical interface
