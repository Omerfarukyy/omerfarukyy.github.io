## About The Project
A full-stack interactive financial web application developed in December 2022. Users can manage portfolios, check live stock market pricing via external APIs, and execute mock financial transactions in a persistent relational database environment.

### Tech Stack
- **Backend:** Python, Flask Framework
- **Frontend & Templates:** HTML5, Jinja2 Templating
- **Database:** SQLite3
- **Integrations:** Real-time Stock Market Quotes & Financial APIs
